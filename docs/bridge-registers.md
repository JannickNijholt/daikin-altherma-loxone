# Onecta → Modbus bridge: register map

Generated by `tools/build_bridge_template.py` from `src/onecta_modbus/registers.py`.

- Registers 1–99 use the Daikin HomeHub (EKRHH) use case 3 layout; *(ext)* = bridge extension.
- PDU address = register − 1. All values are signed 16-bit unless noted.
- Raw `32766` = no data for this unit, `32767` = register not supported.
- Holding registers read back the current Daikin cloud value.
